# GoDHCP v0.1.20 — обновление кэша веб-интерфейса

© 2026 Кислов Роман Сергеевич. Apache License 2.0.

## Исправления

- Версия сборки добавлена к URL JavaScript и CSS. Браузер получает новые файлы после обновления сервера.
- HTML отдаётся с Cache-Control: no-store, статические файлы — с no-cache, требующим проверки актуальности.
- Сохраняются полный экспорт всех доступных аренд по фильтрам (без лимита текущей страницы 200 строк) и сортировка по всем столбцам данных из v0.1.19.
- Добавлены проверки версионированных URL, заголовков кэширования и нестандартного пути веб-интерфейса. Обновлены PDF и инструкция установки.

## Установка

Используйте пакет своей ОС и архитектуры или отдельный бинарник. Набор поставки сохранён: основные DEB/RPM, ALT p10 x86_64, ALT p11 x86_64/aarch64/i586/loongarch64/riscv64, Linux и macOS. e2k исключён.

Проверьте SHA256SUMS, сделайте резервную копию по UPGRADE-V0.1.20.md, установите пакет и перезапустите godhcp.service. После установки один раз обновите страницу через Ctrl+F5; внизу должна отображаться v0.1.20. Для полного CSV очистите ненужные фильтры и нажмите «Найти», затем CSV. Ограничения доступа к VLAN сохраняются.

Для кластера используйте согласованное окно полной остановки по CLUSTER-OPERATIONS.md. Обновление не включает кластер автоматически и не меняет форматы хранения аренд.

## Проверки и ограничения

Конкретные результаты проверок файлов этой сборки — в TEST-RESULTS.json. Прежние VM-испытания не выдаются за повторную квалификацию этой версии. Трёхузловой Raft остаётся экспериментальным. Порты LoongArch/RISC-V проверяются под QEMU, а не на физических хостах. Пакеты и SHA256SUMS не имеют отдельной криптографической подписи.
