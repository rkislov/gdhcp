# GoDHCP для ALT Linux p10

Пакет версии 0.1.7 выпускается отдельно с тегом v0.1.7. RPM пересобран после фиксации исходников; встроенная VCS-ревизия проверяется на совпадение с коммитом тега. Для воспроизведения клонируйте репозиторий и переключитесь на тег v0.1.7.

Пакет x86_64 собирается `bash scripts/build-altlinux-p10.sh` штатным rpm-build в официальном контейнере `alt:p10`. Нужны Go и Docker с поддержкой запуска amd64. Бинарник статический; Node.js не нужен. Результат находится в `dist/altlinux-p10/<version>/`.

Установка от root:

```sh
apt-get install ./godhcp-0.1.7-alt1.p10.x86_64.rpm
```

Пакет создаёт пользователя godhcp, но не запускает DHCP автоматически. Подготовьте `/etc/godhcp/config.yml` на основе `/etc/godhcp/config.yml.example`, секреты в `/etc/godhcp/godhcp.env` и права доступа по [руководству администратора](admin-guide.md). В примере выдача адресов отключена (`server.listen: "-"`); для DHCPv4 нужен `":67"`. UDP 67 должен быть свободен. Не включайте второй независимый DHCP в рабочей сети без согласованного переключения.

```sh
/usr/bin/godhcp -validate -config /etc/godhcp/config.yml
systemctl enable --now godhcp
systemctl status godhcp
```

Инструкция с картинками установлена в `/usr/share/doc/godhcp/godhcp-web-guide.pdf`. Удаление пакета сохраняет рабочую конфигурацию, каталог аренд и служебную учётную запись. Проверка установки в контейнере не заменяет проверку запуска systemd и выдачи адресов на реальном сервере ALT.

Для новых конфигураций API по умолчанию слушает порт 8181. Явно настроенный `api.listen` сохраняет своё значение. Проверка скачанного пакета: `sha256sum -c SHA256SUMS`.
