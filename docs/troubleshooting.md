# Типовые проблемы

**Нет ответа на DISCOVER.** Проверьте, что процесс слушает нужный UDP (`server.listen`, в dev-конфиге это `:6767`, в бою `:67`). Порт 67 на Linux требует root или `CAP_NET_BIND_SERVICE` вместе с `CAP_NET_RAW` и `CAP_NET_ADMIN`.

**Клиент в VLAN молчит.** Имя интерфейса должно содержать VLAN (`eth0.10`) либо пакет должен прийти с меткой, которую читает `PACKET_AUXDATA`. Подсеть и `vlans[].subnet_ref` должны указывать друг на друга.

**Relay отбрасывается.** Смотрите warning в журнале: untrusted giaddr, нет опции 82 при `require_option_82`, либо `hops` выше лимита. Метрики: `dhcp_relay_untrusted_total`, `dhcp_relay_hops_exceeded_total`.

**Circuit ID не даёт VLAN.** `POST /api/v1/parsers/circuit-id/test`. Cisco-шаблон `Gi0/1:vlan20` не совпадает с `Gi0/1.20`. Для своего формата добавьте regex. Мусор в Circuit ID уходит на giaddr и затем на default pool; VLAN, которого нет в конфиге, поиск останавливает.

**Опция 82 пропадает у клиента.** `relay.echo_option_82` по умолчанию включён. Если указатель в YAML задан как `false`, эхо выключено сознательно.

**Сохранение конфига из UI ругается на секрет.** `GET /api/v1/config` маскирует `jwt_secret`. Верните исходное значение или правьте файл на диске и вызовите reload.

**Аренды пропали после рестарта.** Файл SQLite должен лежать на томе (`database.dsn`). Каталог `data/` в репозитории не коммитится. После открытия той же базы аренда поднимается в пул.

**`readyz` отдаёт 503.** База не открылась или пинг соединения не проходит. Для PostgreSQL проверьте DSN и что схема применилась при старте (таблица `schema_migrations`).

**Интерфейс пустой.** Соберите SPA: `make web`. Каталог `internal/webui/dist` вшивается в бинарь. `web.enabled` должен быть `true`.
