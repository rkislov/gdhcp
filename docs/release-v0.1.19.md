# GoDHCP v0.1.19 — полный экспорт CSV и сортировка аренд

© 2026 Кислов Роман Сергеевич. Apache License 2.0.

## Исправления

- CSV выгружает все доступные аренды по применённым фильтрам вместо текущих 25–200 строк. Исправлена потеря адресов из следующих диапазонов, например 10.0.117.* и 10.0.118.*.
- Экспорт сохраняет выбранную сортировку и ограничения доступа к VLAN. При неполном ответе сервера файл не сохраняется как будто он полный.
- Заголовки таблицы сортируют весь список до пагинации: IP, имя, MAC, VLAN, подсеть, relay, состояние и срок аренды. Повторное нажатие меняет направление. IP и relay сортируются численно, даты — хронологически; равные значения упорядочиваются по IP.
- В CSV добавлен адрес relay. Устаревший ответ при быстром переключении сортировки больше не заменяет новый список.
- Обновлены API-документация, инструкции и PDF.

## Установка и обновление

Пакеты DEB/RPM и отдельные бинарники поставляются для той же матрицы, что в v0.1.18: основные Linux-дистрибутивы, ALT p10 x86_64, ALT p11 x86_64/aarch64/i586/loongarch64/riscv64, Linux и macOS. e2k исключён. Сверьте SHA256SUMS и следуйте UPGRADE-V0.1.19.md. После обновления перезагрузите страницу браузера с очисткой кэша (Ctrl+F5).

Релиз не включает кластер автоматически и не меняет форматы хранения аренд. Для обновления кластера используйте согласованное окно полной остановки по CLUSTER-OPERATIONS.md; rolling upgrade смешанных версий не заявлен.

## Проверки и ограничения

Регрессионные тесты покрывают экспорт более 200 аренд, диапазоны 116/117/118, фильтры, права VLAN, сортировку всех полей, IPv4/IPv6, пагинацию и неполный ответ. Конкретные проверки релизных файлов перечислены в TEST-RESULTS.json.

Трёхузловой Raft сохраняет экспериментальный статус. Прежние VM-испытания v0.1.18 не выдаются за повторную квалификацию v0.1.19. LoongArch/RISC-V используют описанные переносы зависимостей; проверка под QEMU не заменяет установку на физических машинах. Пакеты и контрольные суммы не имеют отдельной криптографической подписи.
