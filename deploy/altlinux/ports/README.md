# Дополнения для LoongArch64 / RISC-V

© 2026 Кислов Роман Сергеевич. Apache License 2.0.

Дополнения применяются только к предварительным портам ALT p11. Основной тег v0.1.15 и системный Go module cache не меняются. `scripts/prepare-altlinux-ports.py` проверяет точные версии исходных модулей, копирует их в каталог сборки и создаёт отдельный `portable.mod` с двумя локальными replace. Изменённые модули и этот файл входят в дополнительный архив релиза.

- BoltDB v1.3.1: добавлены определения `maxMapSize`, `maxAllocSize` для двух 64-битных архитектур. Значения совпадают с существующим upstream ARM64/ppc64le. `brokenUnaligned=true` включает предусмотренное самой библиотекой копирование потенциально невыровненных значений.
- bbolt v1.3.5: добавлены отсутствующие определения LoongArch64, совпадающие с существующим upstream RISC-V. Для RISC-V bbolt уже имеет исходный порт; новый файл на нём не компилируется.

Структуры страниц, сериализация, версия файла и протокол Raft не меняются. Новые файлы имеют собственные уведомления Apache-2.0; исходные файлы и MIT-лицензии зависимостей сохранены. Добавления помечены build constraints и не используются на x86_64, aarch64 или i586.

Проверка только успешной компиляции недостаточна. Для этих портов выполняются Go-тесты кластера под QEMU; нативная проверка соответствующего ALT p11 на оборудовании остаётся обязательной. При смене версии любого из двух модулей генератор отказывается применять дополнение автоматически.

Исходные определения: [BoltDB ARM64](https://github.com/boltdb/bolt/blob/v1.3.1/bolt_arm64.go), [bbolt RISC-V](https://github.com/etcd-io/bbolt/blob/v1.3.5/bolt_riscv64.go).
